# Security Policy

The plugin holds a BamDude API key and talks to your farm, so a flaw in it matters. Thank you for reporting
responsibly.

## How to report

**Please do not report security vulnerabilities through public GitHub issues.**

Use GitHub's private vulnerability reporting:

1. Open the [Security tab](https://github.com/kainpl/orca-bamdude/security).
2. Click **Report a vulnerability**.
3. Describe the issue, how to reproduce it, the plugin, OrcaSlicer and BamDude versions, and the impact.

A flaw in the BamDude server itself goes to [BamDude's own advisories](https://github.com/kainpl/bamdude/security).

## What to expect

- Acknowledgement within 48 hours, an assessment within 7 days, and updates as the fix progresses.
- A fix in the next release; critical issues are aimed at within 30 days.
- Credit in the release notes, unless you prefer to stay anonymous.

## Supported versions

Fixes ship in the next release, not as backports: the latest release is supported.
